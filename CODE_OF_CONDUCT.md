# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be kind and patient, assume good intent, criticise ideas and not people, and respect that this is a personal project maintained in spare time. Harassment, personal attacks and publishing other people's private information are not accepted.

## Reporting
If someone behaves in a way that breaks this code, report it privately to the maintainer through GitHub: use "Report content" on the comment or issue, or the private vulnerability reporting form under the repository's Security tab if the matter is sensitive. Please do not discuss it in a public issue. Reports are handled confidentially.

## Enforcement
The maintainer may edit or remove comments, issues and pull requests, and may block people who break this code, following the enforcement guidelines of the Contributor Covenant.
