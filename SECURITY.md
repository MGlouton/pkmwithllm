# Security policy

## Supported versions
Only the latest release on `main` gets fixes.

## What counts as a security problem here
This repository holds Markdown, two small Python scripts and agent settings. Relevant problems are, for example:
- a script or hook that could run unexpected commands, delete files or send data somewhere;
- a rule or setting that lets the agent read `private/` or leak private data;
- a secret or a piece of personal data that was committed by mistake.

## How to report
Please do not open a public issue. Use GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Describe what you found, how to reproduce it and what it affects.

You can expect a first answer within 14 days. This is a personal project maintained in spare time, so fixes may take a while; you will be told what happens.

## Your own vault
Your vault is yours. Never paste personal notes, tokens or private data into an issue or a report here.
