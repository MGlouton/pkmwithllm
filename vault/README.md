# Your vault

Copy this folder to where you keep your notes, open it in Obsidian as a vault and in your agent as the project folder. Then read `CLAUDE.md` and adapt it.

| Folder | Purpose |
|---|---|
| `00_inbox/` | Drop new notes, links and clippings here. The agent files them with `ingest`. |
| `10_wiki/` | The wiki the agent maintains. Start at `index.md`. |
| `20_daily/` | Your daily notes (yours only) and the weekly review notes. |
| `sessions/` | One note per piece of work, so a new session can continue where the last one stopped. |
| `claude-memory/` | What the agent should remember about how you work. You can read and edit it. |
| `private/` | Health, finance, legal and identity documents. Never read by the agent, never in Git. |
| `.claude/` | Skills, scripts and settings for Claude Code. |

The two pages in `10_wiki/` are examples. Keep them, change them or delete them (and their lines in `index.md`).
